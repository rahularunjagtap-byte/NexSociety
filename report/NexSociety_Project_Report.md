## 5. ABSTRACT
**NexSociety** is a modern, responsive web-based platform developed to digitize, streamline, and secure residential housing society operations. Traditional society setups rely heavily on manual paper registers, unverified phone calls at entry gates, and physical notices, leading to security lapses and operational delays.

NexSociety bridges these gaps with a unified, role-based web application serving three stakeholders:
1. **Gate Security Terminal (Gatekeeper Pro):** Digital visitor logbook, guest passcode verification, delivery vehicle recording, and audio-visual beeps.
2. **Resident Portal (Flat A-204):** Visitor pre-approvals (4-digit passcode generation), complaints logging with priority tags, and dues tracking.
3. **Admin & Secretary Command Center:** Real-time KPI cards, 120-unit flat directory with CSV export, helpdesk resolution desk, and broadcast notice publishing.

Developed using HTML5, CSS3 Glassmorphism, Vanilla JavaScript, Web Audio API, and persistent LocalStorage.
